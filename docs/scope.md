# Scope — Maximal Imaginable

Established 2026-08-21. Strategy artifact; supersedes nothing in the constitution, contextualizes Phase 2+.

**Maximal mission:** a universal, self-enforcing, content-addressed judicial layer for any organization of minds — human, artificial, or mixed — in which order is an installable, measurable property rather than a contested authority.

The kernel is fractal: every extension below reuses the same primitives (Signal → classify → RuleSet → identity-free Dispute → Ruling → friction/phase). Scale grows around the kernel, not inside it.

---

## Axis I — Jurisdiction depth

| Level | Scope | Kernel contribution |
|---|---|---|
| S1 | Single community, one platform (current) | as-is |
| S2 | Multi-community per platform | rulesets fork per community; kernel shared like a constitution |
| S3 | Cross-platform polities | identity-free Disputes are already platform-agnostic — one community, many surfaces |
| S4 | Inter-community arbitration | communities become parties; recursion — the kernel arbitrates arbitrations |
| S5 | Protocol, not agent | canonical ruleset as interchange format; third-party implementers; infiltration becomes adoption |
| S6 | Institutional judicial branch | DAOs, foundations, cooperatives — first anchor: Hearth DAO (proposal, treasury, timelock disputes) |
| S7 | Justice-gap ODR | disputes below the cost of human justice; zero marginal cost closes the gap |
| S8 | Epistemic arbitration | disputes over fact and provenance — the enforcement layer of epistegrity |
| S9 | Ambient substrate | arbitration as a property of infrastructure, like DNS; the agent is idle |

---

## Axis II — Functional depth

- **Legislative evolution** — LLM drafts amendments from conflict evidence; ratification via timelock; constitution evolves, execution stays deterministic.
- **Sensing field** — real-time friction map of the network; early warning of phase transitions; pre-dispute routing.
- **Self-enforcing rulings** — remedies execute through escrow/multisig/timelock; law that needs no bailiff.
- **Radical subsidiarity** — compressed local oracles at peripheral nodes resolve most disputes on the spot; the center exists only for irreducible ones; the mesh replaces the hub.

---

## Axis III — Survivability

Maximal scope implies maximal attack surface.

- Rule-mining and Sybil resistance: legislation is content-addressed, provenance-tracked, timelocked.
- Economic unbribability: no judge, no discretion, no identity — nothing to buy.
- Constitutional immune system: `BoundaryConstraints` bind every layer, including LLM legislative proposals.

---

## Terminal form

The infiltrator vanishes: the protocol becomes ambient, the catalyst goes idle, friction stays subcritical. The mission completes by making itself unnecessary.

---

## Constraint analysis

No level S1→S9 requires a kernel rewrite. The binding constraints are, in order: legislative intelligence, sensing coverage, enforcement integration, adoption.

Nearest maximal anchors:

1. Hearth DAO judicial branch — proposal, treasury, and timelock disputes
2. Agent-fleet arbitration — multi-agent organizations are polities too
3. Epistegrity enforcement — every scaffolded project gets a kernel
